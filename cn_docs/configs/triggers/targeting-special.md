# 🎯 目标选择与特殊实体触发器

这些触发器涵盖怪物选择目标、苦力怕进入爆炸准备、末影人直视仇恨、幻翼预生成以及监守者愤怒值变化。

下方每个触发器部分都会说明当前实现所创建的运行时上下文。

| 上下文 | 含义 |
| --- | --- |
| `PLAYER` | 正在检查其激活附魔的玩家。 |
| `SOURCE` | 对事件负责的行为主体或所有者。 |
| `SKILL` | 直接载体或中间实体，例如投射物、鱼钩、烟花或监守者。 |
| `TARGET` | 最终受到影响或被检查的实体。部分事件中可能不存在。 |
| `BLOCK` | 触发器提供的事件方块。 |
| `LOCATION` | 供位置相关条件和能力使用的主要事件位置。 |
| `TRIGGER_ITEM` / `TRIGGER_SLOT` | 选中当前激活附魔的物品和装备槽位。 |
| `EVENT` | 底层 Bukkit/Paper 事件。未复制到其他字段的触发器专用状态，仍可由事件感知型实现通过该事件访问。 |

当某个角色标记为**玩家**时，它会解析为与 `PLAYER` 相同的实体。缺失的角色会解析为 `null`；需要该角色的条件或能力会安全失败或被跳过。

## `on-target`

当某个实体将玩家选为目标时执行。

| 上下文 | 值 |
| --- | --- |
| `PLAYER` / `TARGET` | 被选为目标的玩家 |
| `SOURCE` / `SKILL` | 正在选择目标的实体 |
| `LOCATION` | 玩家所在位置 |
| 额外上下文 | `target_reason`、`target_count`；取消能力会移除已经记录的目标关系 |

## `on-untag`

当一个先前被记录为正在攻击玩家的实体，将目标改为非玩家实体或清除目标时执行。

| 上下文 | 值 |
| --- | --- |
| `PLAYER` / `TARGET` | 先前被选为目标的玩家 |
| `SOURCE` / `SKILL` | 停止将该玩家作为目标的实体 |
| `LOCATION` | 玩家所在位置 |
| 额外上下文 | `target_reason` |

## `on-creeper-explode`

当爆炸准备事件中的实体是玩家，或是当前正将某个玩家作为目标的苦力怕时执行。

| 上下文 | 值 |
| --- | --- |
| `PLAYER` / `TARGET` | 玩家实体，或苦力怕当前锁定的玩家目标 |
| `SOURCE` / `SKILL` | 进入爆炸准备的实体，通常为苦力怕 |
| `LOCATION` | 进入爆炸准备的实体所在位置 |
| 额外上下文 | `original_radius`；可修改的爆炸半径 |
| 注意 | 这不是通用爆炸触发器，也不会提供爆炸掉落倍率 |

## `on-enderman-attack-player`

当 Paper 检查玩家是否正在直视末影人、并可能因此使末影人攻击玩家时执行。取消事件只会阻止直视引发的敌对行为，不会阻止末影人在玩家主动攻击后反击。

| 上下文 | 值 |
| --- | --- |
| `PLAYER` / `TARGET` | 正在接受检查的玩家 |
| `SOURCE` / `SKILL` | 执行检查的末影人 |
| `LOCATION` | 玩家所在位置 |
| 额外行为 | 取消事件会阻止末影人因眼神接触而进入敌对状态 |

## `on-phantom-pre-spawn`

当 Paper 的幻翼预生成事件由某个玩家引发时执行。

| 上下文 | 值 |
| --- | --- |
| `PLAYER` / `SOURCE` / `SKILL` / `TARGET` | 原本将为其生成幻翼的玩家 |
| `LOCATION` / `BLOCK` | 计划生成的位置及该位置的方块 |
| 额外行为 | 取消能力会将 `shouldAbortSpawn` 设置为 true |

## `on-warden-anger-change`

当 Paper 报告监守者对某个玩家的愤怒值发生变化时执行。

| 上下文 | 值 |
| --- | --- |
| `PLAYER` / `SOURCE` | 作为监守者愤怒目标的玩家 |
| `SKILL` / `TARGET` | 监守者 |
| `LOCATION` | 监守者所在位置 |
| 额外上下文 | 旧愤怒值和新愤怒值仍保留在 `WardenAngerChangeEvent` 中；提供可修改的 `warden_anger` 修改器上下文 |
